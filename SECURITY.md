# Security policy

Skills are instructions that agents follow, so a malicious change here could reach every agent that installs them. Reports are taken seriously.

## Reporting

Please report privately through [GitHub's private vulnerability reporting](https://github.com/somesh-ks/skills/security/advisories/new). Do not open a public issue.

Examples worth reporting:

- Instructions in a skill that could make an agent run unsafe commands, leak data, or follow prompt injection
- A compromised or tampered release, tag, or marketplace entry
- A dependency or workflow issue in this repository

You will get a reply within 7 days. Fixes land on `main`; installs that track the default branch pick them up on the next update.
